# ハモリ練習アプリ 🎵

メロディに合わせてハモリ（和声）を練習できるウェブアプリケーションです。

## 機能

- **リアルタイムピッチ検出**: マイクから入力された声の音程をリアルタイムで表示
- **複数のハモリモード**: 3度上・3度下・5度上・オクターブ上から選択可能
- **録音機能**: 自分の歌声を録音して再生・確認
- **視覚的フィードバック**: 波形とピッチグラフで音程を可視化
- **練習パターン**: 音階、アルペジオ、シンプルメロディ、コード進行
- **精度測定**: ハモリの正確さを自動計算
- **カスタマイズ可能**: テンポとキーを調整可能

## 使い方

1. ブラウザで `index.html` を開く
2. マイクへのアクセスを許可する
3. 練習モード（ハモリの種類）を選択
4. 「メロディ再生」でお手本のメロディを聴く
5. 「録音開始」で録音を開始し、メロディに合わせてハモる
6. 「録音停止」で録音を終了し、精度を確認
7. 「再生」で自分の録音を聴く

## キーボードショートカット

- **Space**: 録音の開始/停止
- **P**: メロディ再生

## 技術仕様

- **Web Audio API**: オーディオ処理と合成
- **MediaRecorder API**: 録音機能
- **Canvas API**: リアルタイム可視化
- **Autocorrelation**: ピッチ検出アルゴリズム

## ブラウザ要件

- 最新版の Chrome, Firefox, Safari, Edge
- マイク付きデバイス
- HTTPS環境（localhost除く）
